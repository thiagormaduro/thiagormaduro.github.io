O que é este aplicativo

“Assistentes do Thiago” é um aplicativo pessoal e de usuário único, usado exclusivamente por Thiago Rafalski Maduro para acessar a própria conta Google. Ele não é oferecido a terceiros, não tem cadastro, não tem clientes e não coleta dados de nenhuma outra pessoa. O aplicativo roda em um computador pessoal (macOS) do próprio titular da conta.

Que dados são acessados

Mediante autorização explícita do titular na tela de consentimento do Google, e somente da conta dele:

DadoPara quê
Gmail (ler, buscar, organizar, enviar)Localizar e organizar mensagens do titular e enviar e-mails a pedido dele
Google DriveLer, criar e organizar arquivos do titular
Google AgendaConsultar, criar e alterar compromissos do titular
Google ContatosConsultar e atualizar contatos do titular

O aplicativo não solicita permissão para excluir e-mails de forma definitiva. Exclusões vão para a lixeira e são reversíveis.

Como os dados são usados

Os dados são acessados apenas para executar tarefas pedidas pelo próprio titular, no momento em que ele as pede. Não há coleta em segundo plano para fins próprios, perfilamento, publicidade ou venda de informação.

Processamento por modelo de linguagem. O aplicativo funciona sobre o Claude, da Anthropic. Quando o titular pede uma tarefa que envolve o conteúdo de uma mensagem, arquivo ou compromisso, esse conteúdo é enviado à API da Anthropic para ser interpretado, e fica sujeito à política de privacidade da Anthropic. Nenhum outro terceiro recebe esses dados.

Onde os dados ficam

  • As credenciais de acesso (cliente OAuth e token de atualização) ficam no Chaves do macOS do computador do titular — nunca em arquivos do projeto, serviços de nuvem ou repositórios de código.
  • Conteúdo de e-mail, arquivos e agenda não é armazenado pelo aplicativo: é lido no momento do uso e descartado.
  • Registros operacionais locais guardam apenas o que aconteceu (por exemplo, “uma mensagem foi lida”), sem o conteúdo.

Compartilhamento

Nenhum dado é compartilhado, vendido, alugado ou transferido a terceiros, com a única exceção do processamento pela Anthropic descrito acima, necessário para o funcionamento do aplicativo. Os dados não são usados para treinar modelos de inteligência artificial.

Retenção e exclusão

Como não há armazenamento de conteúdo, não há retenção a expirar. O titular pode encerrar o acesso a qualquer momento:

  • em myaccount.google.com/permissions, removendo o acesso do aplicativo; ou
  • no próprio computador, executando a rotina de revogação do aplicativo, que revoga o token no Google e apaga a credencial do Chaves.

Depois disso, o aplicativo perde qualquer acesso à conta.

Uso limitado

O uso das informações recebidas das APIs do Google por este aplicativo adere à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
